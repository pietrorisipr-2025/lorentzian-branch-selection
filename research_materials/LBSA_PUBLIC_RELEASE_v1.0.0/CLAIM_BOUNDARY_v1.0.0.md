# LBSA Public Claim Boundary v1.0.0

The public claim is intentionally conservative.

LBSA establishes a checked generalized inertial family with three signs of kappa and a set of restricted conditional selectors, together with explicit negative controls. The global physical-origin question is classified NOT_ESTABLISHED.

The release does not claim that Lorentzian kinematics has been derived from quantum theory, hyperbolicity, causality, information theory, stability, or emergence alone. It does not claim a universal no-go theorem or that the finite Lorentzian branch is empirically primitive.

The old Phase-3 arbitrary-future incomparability claim is superseded. The corrected result requires reachable and unreachable displacements at the same positive time separation and is classified PASS_CONDITIONAL_TARGET_ADJACENT.

Mukohyama-Uzan (2013) is included as conditional prior art.
